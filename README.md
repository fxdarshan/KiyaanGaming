# Kiyaan Gaming website

Work in progress: the new website for Kiyaan Gaming, a slot game studio.

## What is here

- `preview/` is a draft of the site as plain web pages: Home, Games, a page per game, Studio, Contact and Privacy Policy. Game titles, artwork and some text are placeholders.
- `tools/build_preview.py` writes the pages in `preview/`. Edit the game list at the top of that file, then run `python3 tools/build_preview.py`.
- `preview/styles.css` holds all colours and fonts.

The draft is published from the `gh-pages` branch so it can be opened in a browser and reviewed.
